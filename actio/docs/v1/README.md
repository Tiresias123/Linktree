# Livrables v1 — archivés

Ces dix sections constituent la première itération du blueprint d'Actio (identité
« Encre et Vélin », cinq rubriques Régulation / Marchés / Guides / Fiscalité / Pro,
infolettre hebdomadaire). Elles sont **remplacées** par les quatre modules `docs/M1-*`
à `docs/M4-*`, écrits sur le cahier des charges révisé : palette et typographies
imposées, piliers Actualités & Régulation / Académie / Comparatifs / Fiscalité &
Droit pratique / Actio Research, infolettre bi-hebdomadaire, Design System et
stratégie SEO/GEO.

Ce qui survit de la v1 sans changement : la base de veille (`research/`), le cadre
de conformité LCAP / Loi 25 / Charte, l'outillage de vérification (`tools/`), et la
règle de vérification avant publication (`docs/v1/annexes/registre-de-verification.md` (v1), remplacé par `docs/annexes/registre-de-verification.md` (v2)).

Ces fichiers sont conservés pour l'historique des arbitrages ; ils ne font plus foi.
